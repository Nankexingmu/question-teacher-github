# 组卷规则

## 输入与组卷蓝图

接受两种入口，也可组合：

- **按学段组卷**：用户提供年级，可能补充学期、册次、章节、题量、满分、时长、难度或题型。优先用资料库中与该范围匹配的教材；只说年级时，根据现有教材覆盖范围提出合理范围并在卷首注明，不能暗自扩大到全年知识。
- **参照试卷组卷**：用户上传清晰的试卷 PDF、照片、截图或文档。按页和题号读取标题、学段、题型、题量、分值、总分、时长、知识点、解题方法与难度梯度；读题图和公式，不凭模糊图片猜条件。先形成简短蓝图，说明可沿用的结构及需要调整的地方。用户明确指定的年级、范围、满分、题量等优先于参考卷。

年级若与参考卷不一致，以用户明确指定的目标年级为准，重新筛选知识点和难度；明显冲突且无法合理迁移时说明原因并询问。未给满分、时长、题量时，参考卷模式尽量沿用其结构；年级模式根据已核对的范围拟定，并在卷首写明。目标范围太宽或教材尚未覆盖时，不用猜测填满试卷。

蓝图至少列出：目标年级/册次与范围、各大题题型及小题数、各题分值和总分、主要知识点及教材小节、难度分布。可用紧凑表格呈现。蓝图是出题依据，若用户只想直接拿到试卷，可简要附在卷后，不必要求用户先确认常规选择。

## 教材与参考卷依据

从 `config.json` 找资料库，检查 `data/source-register.json` 的实际覆盖状态，再查看匹配的 `data/catalogs/`、`data/section-notes/`、题库和教材原页。目录只能证明章节名称和顺序；未整理小节若需要出题，应先核对对应正文、例题与习题。优先使用已核对的教材范围。试卷来源可帮助判断题型和方法，但不替代教材确定教学范围。

资料库已有成批试卷时，先查 `data/exam-index/` 找同一份卷的原卷、解析与答案，以及题型、分值和逐题核对状态。仅从 Word 标题抽取的卷面结构是候选蓝图，使用前须回看原卷；索引里标出的分值冲突不能直接沿用。题库中的试卷题也要看其 `status`，未归类的题不能据此宣称与目标教材匹配。

参考卷仅供结构、考点比例和方法参考。新卷必须重新设计题干、数据、情境或设问；不直接拼贴原题，不以机械改数值作为整卷的主要方式。允许相同核心知识点和解题方法。若参考卷有题目无法辨认，明确指出题号或页码，能处理的部分继续，关键结构无法确定时再请用户补清晰页。

资料库没有目标年级教材时，告知用户缺少教材依据，请其上传对应教材；若用户明确同意先要草稿，可按通用知识生成并在卷首标明“未按所需教材核对”。资料库只整理了部分章节时，可以只针对已核对范围组卷，或先回看原教材页；不要把仅有目录的章节说成题型已验证。

## 出题、验算与交付

1. 按蓝图生成完整试卷：标题、年级与范围、考试时间、满分、必要说明、大题标题、小题编号、每题分值和作答空间提示。选择、填空、解答等题型的数量与蓝图一致；题目由易到难，避免同方法的无意义重复。
2. 逐题独立求解，检查条件充分、答案唯一或明确列出多解、图形与题干一致、所需知识不超目标学段；复核选择题选项与正确项、填空题表述、解答题步骤与评分点。总分必须等于各题分值之和，题号连续，参考卷的结构改动应能说明原因。
3. 默认交付两部分：**可直接发给学生的试卷**，以及与题号一一对应的**答案与解析/评分参考**。答案、组卷蓝图和教材核对说明都放在学生试卷之外，便于直接复制或打印学生卷。组卷说明简列知识点覆盖与资料依据的实际核对状态。用户要求先只给试卷时保留答案，等其在同一会话提出再给。
4. 用户需要可打印文件时，按其指定格式输出；未指定格式可先给排版清楚的文本，必要时再导出文件。若生成 Markdown 文件，行内公式使用 `$...$`，独立公式使用 `$$...$$`，交付前检查公式定界符和实际显示效果。若参考卷只是本次组卷的样式参考，不自动入库；用户明确要求收录时另按资料入库流程执行。
