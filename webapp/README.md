# 出题老师本机网页

在项目根目录运行：

```powershell
python webapp/server.py
```

服务启动后会自动打开 `http://127.0.0.1:8765/`。也可以运行 `webapp/启动网页.ps1`。关闭终端即可停止网页服务。

网页提供知识点出题、错题巩固、按年级或参考卷组卷、资料入库，以及资料库概况。后台调用现有 `agent/teacher.py` 和已登录的 Codex CLI，因此本机须能运行 `codex` 命令。所有资料保存在本项目；服务仅监听 `127.0.0.1`，不会公开到互联网。一次上传支持不超过 100 MB 的 PDF、DOCX、PNG、JPG、WEBP。

如端口 8765 已被占用，可设置 `QUESTION_TEACHER_WEB_PORT` 环境变量，但需手动打开对应端口。处理结果会显示在当前页面；刷新页面后任务结果不会长期保存，已入库资料仍保存在资料库中。
